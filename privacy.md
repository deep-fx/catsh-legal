# Privacy Policy for Catsh Bot

**Last Updated: June 2025**

Catsh does not collect, store, or share any personal user data. 

- The bot only processes message content for moderation purposes (deleting spam, filtering bad words)
- No messages are stored permanently
- No user data is sold or shared with third parties
- Server settings (prefix, warn limits) are stored locally in the server's database
- Temporary data (AFK status, warnings, notes) is stored only while relevant

For questions, contact us via our support server.

**Data We Store:**
- Server IDs (for settings)
- User IDs (for warnings, notes, AFK status - deleted when cleared)
- No email, no passwords, no personal information

**Data Deletion:** Server owners can clear all data by kicking the bot. Users can request data deletion via support server.
